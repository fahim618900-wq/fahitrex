Welcome

শুরু করুন আরও দেখুন

সুন্দর Design

স্বচ্ছ কাঁচের মতো Glassmorphism interface এবং আপনার দেওয়া background image।

Responsive

মোবাইল, ট্যাবলেট ও কম্পিউটার— সব ধরনের screen-এর জন্য স্বয়ংক্রিয়ভাবে মানিয়ে যাবে।

Light / Dark

উপরের Theme button চাপলেই Light এবং Dark mode পরিবর্তন হবে।

Fast

কোনো framework ছাড়াই HTML, CSS এবং JavaScript দিয়ে তৈরি।

Modern UI

Blur, transparency, smooth animation এবং modern spacing ব্যবহার করা হয়েছে।

সহজে পরিবর্তনযোগ্য

Menu, লেখা, button এবং অন্যান্য অংশ সহজেই পরিবর্তন করতে পারবেন।

Contact

আপনার প্রয়োজন অনুযায়ী এই অংশে যোগাযোগের তথ্য যোগ করতে পারবেন।

আপনার ছবির Path শুধু নিশ্চিত করবেন ফোল্ডারটি এমন: YourWebsite/ │ ├── index.html │ └── path/ ├── logol.m.png ├── logod.m.png ├── logol.p.png └── logod.p.png এখানে Theme button চাপলে Light ↔ Dark হবে এবং "localStorage"-এর কারণে পেজ রিফ্রেশ করলেও নির্বাচিত Theme থাকবে। মোবাইলে আবার PC-এর navigation না দেখিয়ে ☰ Menu দেখাবে, আর PC-তে সরাসরি Home / About / Services / Contact দেখা যাবে।
